# ACE
This is a medicine delivery robot called ACE.
It will be able to move autonomously.
It will use AI for active obstacle avoidance and dynamic speech.
The main components are:
  * Raspberry Pi (I used a Raspberry Pi 3B+ but anything higher will also work)
  * Camera
  * Microphone
  * 4 DC Motors (For Main Movement)
  * 1 Servo (For Precise movement of the camera)
  * A Speaker
  * 2 Power banks (1 for Pi and other components, other as a dedicated motor power supply)
  * Passive Suspension
Uses Python due to its ease of use and community availability
